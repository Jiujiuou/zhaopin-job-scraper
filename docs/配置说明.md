# 配置说明

`zhaopin_jobs.py` 通过一个 JSON 配置文件控制全部行为。以下为所有配置项详解。

## 快速上手

**必填 4 项**：

```json
{
  "job_title": "嵌入式开发",        // 报告标题（用于文件名和报告头部）
  "keywords": ["嵌入式", "嵌入式软件"],  // 智联搜索关键词，至少 1 个
  "city": "深圳",                  // 城市名（中文），或直接写 jl 编码 "765"
  "salary_min_k": 15              // 薪资下限（单位 K，15 = 1.5万）
}
```

**其余全部可选**，不写或留空数组 = 不启用对应过滤。

## 完整配置项

### 基本信息

| 配置 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `job_title` | string | ✅ | 报告标题与文件名用 |
| `keywords` | string[] | ✅ | 智联搜索关键词。多个关键词会分别搜索后合并去重 |
| `city` | string | ✅ | 城市名（如 `深圳`），或智联城市 jl 编码（如 `765`） |
| `salary_min_k` | number | ✅ | 薪资下限（K）。`20` = 2 万以上，`0` = 不限 |
| `salary_max_k` | number | ❌ | 薪资上限（K）。默认 100 |

### 过滤规则（全可选）

| 配置 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `blacklist` | string[] | `[]` | 公司名黑名单，**模糊匹配**（`"科锐"` 会匹配 `科锐尔人力资源`） |
| `include_terms` | string[] | `[]` | 标题**必须**包含至少一个词才通过（不区分大小写） |
| `exclude_terms` | string[] | `[]` | 标题包含任一词即排除 |
| `dispatch_terms` | string[] | `["派遣"]` | 标题含这些词视为派遣/外包岗，排除 |

> 提示：`include_terms` 和 `exclude_terms` 同时为空时，脚本只按薪资+黑名单过滤——适合想"先看全量再人工挑"的用户。

### 行为参数（一般用默认）

| 配置 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `hr_active_days` | number | `7` | HR 活跃度阈值（天）。报告按此标注活跃/未知 |
| `max_pages` | number | `12` | 每个关键词最大翻页数（每页 20 条） |
| `sort_by` | string | `"salary"` | 排序：`salary` 薪资优先 / `hr` HR活跃优先 |
| `output_dir` | string | `"."` | 报告输出目录 |

## 城市配置

`city` 支持两种写法：

1. **中文名**：`"深圳"` —— 脚本自动查 `cities.json`（内置 260+ 城市，已验证）
2. **jl 编码**：`"765"` —— 直接指定，适合 cities.json 没有的城市

### 如何获取任意城市的 jl 编码

1. 浏览器打开 `www.zhaopin.com`，切到目标城市
2. 搜索任意岗位
3. 看地址栏 URL，`jl` 后面的数字就是编码
   如 `https://www.zhaopin.com/sou/jl765/...` → 编码 `765`

## 薪资格式说明

智联岗位薪资有 4 种写法，脚本全部自动识别并按 **K（千元/月）** 统一换算：

| 原始格式 | 示例 | 解析为 |
|----------|------|--------|
| 万 | `1.8-2.4万` | 上限 24K |
| 元 | `8000-15000元` | 上限 15K |
| K | `15-22K` | 上限 22K |
| 面议 | `面议` | 无法解析，默认过滤 |

> 判断标准：**薪资上限 ≥ `salary_min_k` 才通过**。
